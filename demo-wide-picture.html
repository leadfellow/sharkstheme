Configuration Options

📏 Spacing

  • None: 0
  • Small: 2rem
  • Medium: 4rem (default)
  • Large: 6rem

🔲 Border Radius

  • None: 0 (default)
  • Small: 8px
  • Medium: 16px
  • Large: 24px

✨ Effects

  • Shadow: Yes/No
  • Caption: Optional
  • Alt Text: Custom
  • Lazy Load: Enabled
