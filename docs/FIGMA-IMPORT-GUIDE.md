# 🎨 Figma Design Tokens Import Guide

## Ülevaade

Sharks teema võimaldab importida design token'eid otse Figmast WordPress'i admin paneelis. See automatiseerib värviskeemide, typograafia ja spacing'u uuendamise protsessi.

## Kuidas leida Sharks Settings'it?

1. **WordPress Admin** → Vasak menüü
2. **"Sharks Settings"** (ikoon: 🎨)
3. Kolm alamlehte:
   - **Sharks Settings** - Põhiseadistused (värvid, typo, spacing)
   - **Figma Import** - Kiire import JSON/CSS'ist
   - **Preview** - Eelvaade token'itest

---

## Meetodid Figma Token'ite importimiseks

### Meetod 1: Käsitsi sisestamine (lihtne)

1. **Ava Sharks Settings** → **Sharks Settings**
2. **Täida väljad:**
   - **Colors:** Vali värve color picker'ist
   - **Typography:** Sisesta font-family, sizes
   - **Spacing:** Määra space-1 kuni space-5
   - **Border Radius:** Määra radius-sm kuni radius-2xl
3. **Salvesta:** Kliki "Save Settings"

✅ **Genereeritakse automaatselt:**
- `assets/css/00-settings/variables.css` (uus CSS)
- `theme.json` (värvipalett Gutenberg'ile)

---

### Meetod 2: CSS Variables import (soovitatud)

#### Samm 1: Ekspordi Figmast

**Figma → Inspect panel:**

1. Vali Figmas element, millel on style
2. Parem paneel → **Inspect**
3. Kopeeri CSS code, mis sisaldab:
   ```css
   --color-primary: #0066CC;
   --color-secondary: #00A3E0;
   --fs-h1: clamp(2rem, 4vw, 3rem);
   ```

#### Samm 2: Impordi WordPress'i

1. **Sharks Settings** → **Figma Import**
2. **Kleebi CSS Variables tekstikasti**
3. Kliki **"Parse & Import Tokens"**
4. Kontrollime üle → **Salvesta**

✅ Parser tuvastab:
- `--color-*` → Värvid
- `--fs-*` → Font sizes
- `--space-*` → Spacing
- `--radius-*` → Border radius

---

### Meetod 3: JSON import (Figma pluginiga)

#### Samm 1: Installi Figma plugin

**Soovitatud pluginad:**
- [Design Tokens](https://www.figma.com/community/plugin/888356646278934516)
- [Tokens Studio for Figma](https://www.figma.com/community/plugin/843461159747178978)

#### Samm 2: Ekspordi JSON

1. **Figma** → **Plugins** → **Design Tokens**
2. **Export** → Vali "JSON" format
3. Kopeeri JSON sisu:
   ```json
   {
     "global": {
       "color": {
         "primary": {"value": "#0066CC"},
         "secondary": {"value": "#00A3E0"}
       }
     }
   }
   ```

#### Samm 3: Impordi

1. **Sharks Settings** → **Figma Import**
2. Kleebi JSON **"Figma Tokens (JSON)"** tekstikasti
3. Kliki **"Parse & Import Tokens"**
4. Vaata üle → Salvesta

## Mida see genereerib?

### 1. `variables.css`

**Asukoht:** `assets/css/00-settings/variables.css`

```css
/**
 * Design Tokens - Generated from Sharks Settings
 * Last updated: 2025-10-28 15:30:00
 * DO NOT EDIT THIS FILE MANUALLY
 */

:root {
  /* Colors */
  --color-primary: #0066CC;
  --color-secondary: #00A3E0;
  --color-accent: #FF6B35;
  
  /* Typography */
  --font-sans: "Inter", system-ui, sans-serif;
  --fs-h1: clamp(2rem, 4vw, 3rem);
  
  /* Spacing */
  --space-1: 0.5rem;
  --space-2: 1rem;
  
  /* Border Radius */
  --radius-sm: 4px;
}
```

### 2. `theme.json` (värvipalett)

**Asukoht:** `theme.json`

```json
{
  "settings": {
    "color": {
      "palette": [
        {"slug": "primary", "name": "Primary", "color": "#0066CC"},
        {"slug": "secondary", "name": "Secondary", "color": "#00A3E0"}
      ]
    }
  }
}
```

## Troubleshooting

### ❓ Sharks Settings menüü ei ilmu

**Lahendus:**
1. Kontrolli, kas ACF Pro on aktiveeritud
2. Kontrolli `inc/admin-settings.php` laadimist
3. Vaata konsoolist: WP Admin → Debug notice

### ❓ Import ei tööta

**Kontrolli:**
1. **JSON formaat:** Peab olema valid JSON
2. **CSS formaat:** Peab sisaldama `--color-*` või `--fs-*`
3. Vajuta F12 → Console → Vaata vigu

### ❓ Värvid ei muutu frontendis

**Lahendused:**
1. **Tyhjenda cache:**
   - Browser cache (Ctrl + Shift + R)
   - WordPress cache
2. **Kontrolli faile:**
   - `assets/css/00-settings/variables.css` - kas muudetud?
   - `site.css` - kas importib variables.css?

### ❓ Backup & Restore

**Automaatne backup:**
- Iga salvestamisel tehakse backup:
  - `variables.backup.css`
  - `theme.backup.json`

**Taastamine:**
```bash
cd assets/css/00-settings/
cp variables.backup.css variables.css
```

## Best Practices

### 1. Nimetamise konventsioon

**Figmas:**
```
Color Styles:
- Primary/Default
- Primary/Hover
- Text/Body
- Text/Light
```

**CSS Variables:**
```css
--color-primary: #0066CC;
--color-primary-hover: #0052A3;
--color-text: #1A1A1A;
--color-text-light: #666666;
```

### 2. Responsive Typography

**Kasuta `clamp()`:**
```css
--fs-h1: clamp(2rem, 4vw, 3rem);
/*           min   vw   max */
```

### 3. Spacing Scale

**8px grid system:**
```css
--space-1: 0.5rem;  /* 8px */
--space-2: 1rem;    /* 16px */
--space-3: 1.5rem;  /* 24px */
--space-4: 2rem;    /* 32px */
--space-5: 3rem;    /* 48px */
```

## API & Development

### Programmeerja jaoks

**Õige variables kasutamine:**
```php
// BAD: hard-coded
.btn { background: #0066CC; }

// GOOD: token
.btn { background: var(--color-primary); }
```

**ACF field'ide lugemine:**
```php
$primary_color = get_field('color_primary', 'option');
$font_sans = get_field('font_sans', 'option');
```

**Funktsioonid:**
```php
sharks_generate_css_variables(); // Genereeri variables.css
sharks_update_theme_json();      // Uuenda theme.json
```
