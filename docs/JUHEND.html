Näidis: 3 Blokiga Projekt

Praktiline näide projektist, kus on 3 ACF blokki:

minu-teema/
│
├── style.css
├── functions.php
├── index.php
│
├── acf-json/
│   ├── group_hero_banner.json        # 1. blokk
│   ├── group_services.json           # 2. blokk
│   └── group_contact_form.json       # 3. blokk
│
└── template-parts/
    └── blocks/
        ├── hero-banner/
        │   └── hero-banner.php       # 1. blokk template
        ├── services/
        │   └── services.php          # 2. blokk template
        └── contact-form/
            └── contact-form.php      # 3. blokk template

functions.php sisaldab:

<?php
// ACF Local JSON
add_filter('acf/settings/save_json', function($path) {
    return get_stylesheet_directory() . '/acf-json';
});

add_filter('acf/settings/load_json', function($paths) {
    unset($paths[0]);
    $paths[] = get_stylesheet_directory() . '/acf-json';
    return $paths;
});

// Registreeri blokid
add_action('acf/init', function() {
    if (!function_exists('acf_register_block_type')) return;
    
    // 1. Hero Banner
    acf_register_block_type([
        'name' => 'hero-banner',
        'title' => 'Hero Banner',
        'render_template' => 'template-parts/blocks/hero-banner/hero-banner.php',
        'category' => 'layout',
        'icon' => 'cover-image',
    ]);
    
    // 2. Services
    acf_register_block_type([
        'name' => 'services',
        'title' => 'Services',
        'render_template' => 'template-parts/blocks/services/services.php',
        'category' => 'layout',
        'icon' => 'grid-view',
    ]);
    
    // 3. Contact Form
    acf_register_block_type([
        'name' => 'contact-form',
        'title' => 'Contact Form',
        'render_template' => 'template-parts/blocks/contact-form/contact-form.php',
        'category' => 'layout',
        'icon' => 'email',
    ]);
});

[kleebi siia Figma Make HTML]

FIGMA CSS:
[kleebi siia Figma Make CSS]

GENEREERI KÕIK FAILID:

1. REGISTREERING (functions.php):
   - Lisa acf_register_block_type() kood
   - Block name: hero-banner
   - Category: layout
   - Icon: cover-image

2. PHP TEMPLATE (template-parts/blocks/hero-banner/hero-banner.php):
   - Kasuta get_field() ACF väljadele
   - Lisa dummy data kui väljad tühjad
   - Kasuta esc_html(), esc_attr(), esc_url()
   - Block attributes: anchor, className, align

3. ACF JSON FAIL (acf-json/group_hero_banner.json):
   - Loo täielik ACF field group JSON
   - Location: Block == acf/hero-banner
   - Väljad mida tahan muuta:
     * pealkiri (text, required, default: "Tere tulemast")
     * alapealkiri (textarea)
     * nupu_tekst (text, default: "Võta ühendust")
     * nupu_link (url, default: "#contact")
     * taustapilt (image)
     * block_anchor (text, placeholder: "hero", instructions: "Ankru nimi linkimiseks")

4. CSS (style.css):
   - Puhasta Figma CSS
   - Lisa .block-hero-banner klassid
   - Responsive (@media)
   - Hover efektid

OLULINE:
- ACF JSON peab olema TÄIELIK ja VALID JSON
- Kasuta "key" formaadis: "field_hero_banner_pealkiri"
- Kasuta "group_hero_banner" group key'na
- Lisa default_value kõigile väljadele

❓ KKK (Korduma Kippuvad Küsimused)

❓ Block ei ilmu Gutenberg'is?

Lahendused:
  1. Mine: Settings → Permalinks → Save Changes
  2. Kontrolli, kas ACF Pro on aktiveeritud
  3. Kontrolli functions.php - kas block on registreeritud?
  4. Kontrolli, kas acf-json/group_*.json fail eksisteerib

❓ "Sync available" ei ilmu?

Põhjused:
  1. JSON fail on vigane - kontrolli syntax'it (kasuta JSONLint.com)
  2. Kaust puudub - kontrolli, kas acf-json/ kaust eksisteerib
  3. Õigused - kaust peab olema kirjutatav (chmod 755)
  4. Juba sünkroniseeritud - field group on juba WordPressis

❓ Kuidas muuta olemasolevat field group'i?

2 võimalust:
  1. WordPressis: Muuda Custom Fields → Field Groups → Salvesta → JSON uueneb automaatselt
  2. Cursor'is: Muuda JSON faili → Mine WordPressis → Sync available → Sync

❓ JSON fail on vigane?

Kontrolli:
  1. Kopeeri JSON sisu
  2. Mine: jsonlint.com
  3. Kleebi ja vajuta "Validate JSON"
  4. Paranda vead

Levinud vead:

  • Puuduv koma
  • Liigne koma viimase elemendi järel
  • Jutumärgid valesti
  • Puuduvad sulud

❓ Kuidas lisada Repeater field?

JSON näide: 
{
  "key": "field_cards",
  "name": "cards",
  "type": "repeater",
  "button_label": "Lisa kaart",
  "min": 1,
  "max": 10,
  "layout": "block",
  "sub_fields": [
    {
      "key": "field_card_title",
      "name": "title",
      "type": "text",
      "required": 1
    },
    {
      "key": "field_card_text",
      "name": "text",
      "type": "textarea"
    }
  ]
}

PHP kasutus:

<?php
$cards = get_field('cards');
if ($cards):
    foreach ($cards as $card):
        echo '<div class="card">';
        echo '<h3>' . esc_html($card['title']) . '</h3>';
        echo '<p>' . esc_html($card['text']) . '</p>';
        echo '</div>';
    endforeach;
endif;
?>

🐧 UBUNTU HELP: WordPress Installimine

1 Uuenda Süsteemi

sudo apt update
sudo apt upgrade -y

2 Installi LAMP Stack

Apache, MySQL, PHP:

# Apache
sudo apt install apache2 -y

# MySQL
sudo apt install mysql-server -y

# PHP ja moodulid
sudo apt install php php-mysql php-curl php-gd php-mbstring php-xml php-xmlrpc php-zip -y

# Taaskäivita Apache
sudo systemctl restart apache2

3 Loo MySQL Andmebaas

# Logi MySQL'i sisse
sudo mysql -u root

# MySQL käsud:
CREATE DATABASE wordpress;
CREATE USER 'wpuser'@'localhost' IDENTIFIED BY 'tugevparool123';
GRANT ALL PRIVILEGES ON wordpress.* TO 'wpuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

4 Lae Alla WordPress

# Mine Apache kausta
cd /var/www/html

# Lae alla WordPress
sudo wget https://wordpress.org/latest.tar.gz

# Paki lahti
sudo tar -xzvf latest.tar.gz

# Kustuta arhiiv
sudo rm latest.tar.gz

5 Seadista Õigused (OLULINE!)

# Muuda omanikku
sudo chown -R www-data:www-data /var/www/html/wordpress

# Seadista kaustade õigused (755)
sudo find /var/www/html/wordpress -type d -exec chmod 755 {} \;

# Seadista failide õigused (644)
sudo find /var/www/html/wordpress -type f -exec chmod 644 {} \;

# wp-content peab olema kirjutatav
sudo chmod -R 775 /var/www/html/wordpress/wp-content
sudo chown -R www-data:www-data /var/www/html/wordpress/wp-content
⚠️ Oluline: Ilma õigete õigusteta ei saa pluginaid installida ega teemade faile luua!

6 Seadista wp-config.php

# Kopeeri näidisfail
sudo cp /var/www/html/wordpress/wp-config-sample.php /var/www/html/wordpress/wp-config.php

# Muuda andmebaasi seadistusi
sudo nano /var/www/html/wordpress/wp-config.php

Muuda järgmised read:

define('DB_NAME', 'wordpress');
define('DB_USER', 'wpuser');
define('DB_PASSWORD', 'tugevparool123');
define('DB_HOST', 'localhost');

Mine: http://localhost/wordpress või http://your-ip/wordpress

sudo chmod -R 775 /var/www/html/wordpress/wp-content/themes/minu-teema/acf-json

# Kontrolli Apache staatust
sudo systemctl status apache2

# Taaskäivita Apache
sudo systemctl restart apache2

# Vaata PHP versiooni
php -v

# Vaata MySQL staatust
sudo systemctl status mysql

# Vaata Apache error log'e
sudo tail -f /var/log/apache2/error.log

# Vaata failide õigusi
ls -la /var/www/html/wordpress/wp-content/themes/

⚠️ Levinud Probleemid

  • "Cannot write to directory" → Kontrolli õigusi (chmod 775)
  • "Permission denied" → Kontrolli omanikku (chown www-data:www-data)
  • "500 Internal Server Error" → Vaata error.log faili
  • ACF JSON ei salvesta → acf-json/ kaust peab olema kirjutatav (775)
