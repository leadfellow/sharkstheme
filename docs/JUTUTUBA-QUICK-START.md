# 🚀 Jututuba - Kiire Alustamine

## 3 sammu käivitamiseks

### 1️⃣ Käivita PHP server
```bash
cd docs
php -S localhost:8000
```

### 2️⃣ Ava brauser
Ava: `http://localhost:8000/index.html`

### 3️⃣ Kliki "💬 Jututuba" tab'ile
Valmis! Nüüd saad kommenteerida.

---

## 📝 Kasutamine

1. **Sisesta nimi** (2-50 tähemärki)
2. **Kirjuta kommentaar** (3-500 tähemärki)
3. **Vajuta "Saada kommentaar"**
4. **Kommentaar ilmub kohe!**

---

## ✨ Funktsioonid

- ✅ Reaalajas kommentaarid
- ✅ Tähemärkide loendur
- ✅ Automaatne kuupäev ("Just nüüd", "5 min tagasi")
- ✅ Responsive disain
- ✅ Turvaline (HTML escape, valideerimine)

---

## 🔧 Troubleshooting

### Ei tööta?
```bash
# Kontrolli PHP versiooni
php -v

# Anna õigused
chmod 755 docs

# Vaata error log'i
tail -f /var/log/apache2/error.log
```
