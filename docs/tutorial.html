<?php
// Laadi CSS failid õiges järjekorras
add_action('wp_enqueue_scripts', function() {
    // 1. Settings (muutujad)
    wp_enqueue_style('variables', get_template_directory_uri() . '/assets/css/10-settings/variables.css');
    
    // 2. Elements (põhielemendid)
    wp_enqueue_style('typography', get_template_directory_uri() . '/assets/css/20-elements/typography.css');
    wp_enqueue_style('buttons', get_template_directory_uri() . '/assets/css/20-elements/buttons.css');
    wp_enqueue_style('forms', get_template_directory_uri() . '/assets/css/20-elements/forms.css');
    
    // 3. Components (blokid)
    wp_enqueue_style('hero-banner', get_template_directory_uri() . '/assets/css/30-components/hero-banner.css');
    wp_enqueue_style('services', get_template_directory_uri() . '/assets/css/30-components/services.css');
    wp_enqueue_style('contact-form', get_template_directory_uri() . '/assets/css/30-components/contact-form.css');
    
    // 4. Utilities (responsive, helpers)
    wp_enqueue_style('responsive', get_template_directory_uri() . '/assets/css/40-utilities/responsive.css');
    wp_enqueue_style('helpers', get_template_directory_uri() . '/assets/css/40-utilities/helpers.css');
    
    // JavaScript failid
    wp_enqueue_script('main-js', get_template_directory_uri() . '/assets/js/main.js', [], '1.0', true);
    wp_enqueue_script('hero-banner-js', get_template_directory_uri() . '/assets/js/hero-banner.js', ['jquery'], '1.0', true);
    wp_enqueue_script('services-js', get_template_directory_uri() . '/assets/js/services.js', ['jquery'], '1.0', true);
    wp_enqueue_script('contact-form-js', get_template_directory_uri() . '/assets/js/contact-form.js', ['jquery'], '1.0', true);
});

// FAQ Accordion
document.addEventListener('DOMContentLoaded', function() {
    const faqItems = document.querySelectorAll('.faq-item');
    
    faqItems.forEach(item => {
        const question = item.querySelector('.faq-item__question');
        const answer = item.querySelector('.faq-item__answer');
        const icon = item.querySelector('.faq-item__icon');
        
        question.addEventListener('click', () => {
            // Sulge kõik teised
            faqItems.forEach(otherItem => {
                if (otherItem !== item && otherItem.classList.contains('active')) {
                    otherItem.classList.remove('active');
                    otherItem.querySelector('.faq-item__answer').style.maxHeight = null;
                    otherItem.querySelector('.faq-item__icon').textContent = '+';
                }
            });
            
            // Toggle praegune
            item.classList.toggle('active');
            
            if (item.classList.contains('active')) {
                answer.style.maxHeight = answer.scrollHeight + 'px';
                icon.textContent = '−';
            } else {
                answer.style.maxHeight = null;
                icon.textContent = '+';
            }
        });
    });
});

🌿 3. Branch'id (Harud)

Mis on Branch?

Branch on eraldi "haru" projektis, kus saad töötada ilma põhikoodi mõjutamata.

✅ Tüüpiline Töövoog:

  • main - Põhikood (stabiilne versioon)
  • develop - Arenduskood
  • feature/hero-banner - Uus funktsioon
  • bugfix/contact-form - Vea parandus

Branch'ide Haldamine

# Vaata kõiki branch'e
git branch

# Vaata kõiki branch'e (ka remote)
git branch -a

# Loo uus branch
git branch feature/hero-banner

# Lülitu teisele branch'ile
git checkout feature/hero-banner

# Loo ja lülitu korraga
git checkout -b feature/services

# Kustuta branch
git branch -d feature/hero-banner

# Kustuta branch (force)
git branch -D feature/hero-banner

Branch'ide Ühendamine (Merge)

# Lülitu branch'ile, KUHU tahad merge'ida
git checkout main

# Merge'i teine branch siia
git merge feature/hero-banner

# Merge koos commit sõnumiga
git merge feature/hero-banner -m "Merge hero banner feature"
⚠️ Konfliktid: Kui kaks inimest muutsid sama faili, tekib konflikt. Git näitab konflikti kohti failides: 
<<<<<<< HEAD
Sinu versioon
=======
Teise inimese versioon
>>>>>>> feature/hero-banner
Paranda käsitsi, siis git add ja git commit.

⏪ 4. Muudatuste Tagasivõtmine

🔄 git reset - Commit'ide Tagasivõtmine

# Võta tagasi viimane commit (säilita muudatused)
git reset --soft HEAD~1

# Võta tagasi viimane commit (muudatused jäävad unstaged)
git reset HEAD~1

# Võta tagasi viimane commit (KUSTUTA muudatused!)
git reset --hard HEAD~1

# Võta tagasi 3 viimast commit'i
git reset --hard HEAD~3

# Lähtesta konkreetsele commit'ile
git reset --hard abc1234
⚠️ OHTLIK: git reset --hard KUSTUTAB muudatused jäädavalt! Kasuta ettevaatlikult!

↩️ git revert - Turvaline Tagasivõtmine

Revert loob UUE commit'i, mis tühistab vana commit'i (ei kustuta ajalugu):

# Tühista viimane commit
git revert HEAD

# Tühista konkreetne commit
git revert abc1234

# Tühista ilma automaatse commit'ita
git revert --no-commit abc1234
✅ Soovitatud: Kasuta git revert avalikes branch'ides (main, develop), mitte git reset!

🗑️ git restore - Failide Taastamine

# Taasta fail viimasest commit'ist (kustuta muudatused)

# Taasta kõik failid
git restore .

# Eemalda fail staging area'st (aga säilita muudatused)
git restore --staged functions.php

# Taasta fail konkreetsest commit'ist
git restore --source=abc1234 functions.php

# Kustuta untracked failid
git clean -f

# Kustuta ka kaustad
git clean -fd

# Kustuta ka .gitignore failid

🚨 8. Levinud Probleemid ja Lahendused

❌ "Your branch is behind..."

Probleem: Keegi tegi serverisse muudatusi.

Lahendus:

git pull

❌ "Merge conflict"

Probleem: Kaks inimest muutsid sama faili.

Lahendus:

# 1. Ava fail ja paranda konfliktid käsitsi
# 2. Lisa parandatud fail
git add functions.php
# 3. Commit
git commit -m "Lahenda merge konflikt"

❌ "Permission denied (publickey)"

Probleem: SSH võti puudub või on vale.

Lahendus:

# Genereeri SSH võti
ssh-keygen -t ed25519 -C "sinu.email@example.com"

# Kopeeri avalik võti
cat ~/.ssh/id_ed25519.pub

# Lisa GitHub'i: Settings → SSH and GPG keys → New SSH key

❌ Commit'isin vale faili

Lahendus:

# Võta commit tagasi (säilita muudatused)
git reset --soft HEAD~1

# Eemalda fail staging area'st
git restore --staged vale-fail.php

# Commit uuesti
git commit -m "Õige commit"

❌ Tahan kõike algusest alustada

Lahendus:

# HOIATUS: See kustutab KÕIK kohalikud muudatused!
git fetch origin
git reset --hard origin/main
git clean -fd

🖼️ 2. Lisa Prompti Pilte - Näita, Mida Tahad

🐛 4. Kui Jooksed Kinni - Jaga Error Log'e

⚠️ Kui 4-5 promptiga ei suuda Cursor errorit lahendada:
Anna talle täpsed error log'id!

A) PHP Errorid - error.log

# Ubuntu/Linux
sudo tail -100 /var/log/apache2/error.log

# XAMPP (Windows)
C:\xampp\apache\logs\error.log

# LocalWP
~/Local Sites/[site-name]/logs/php/error.log

Prompt Cursor'ile:

Sain PHP errori. Siin on error.log viimased 100 rida:

[KLEEBI error.log SISU SIIA]

Palun paranda see error.

B) JavaScript Errorid - Console Log

  1. Ava brauser (Chrome/Firefox)
  2. Vajuta F12
  3. Mine Console tab'ile
  4. Kopeeri kõik punased errorid

Prompt Cursor'ile:

Sain JavaScript errori brauseris. Siin on console log:

[KLEEBI CONSOLE ERROR SIIA]

Palun paranda see error.

C) WordPress Debug Mode

Lisa wp-config.php faili:

define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);

Errorid salvestatakse: wp-content/debug.log

💡 Pro tip: Mida täpsem error kood, seda kiirem lahendus! Ära kirjuta "ei tööta", vaid näita täpset error koodi.
