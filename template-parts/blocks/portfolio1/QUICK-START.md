# Portfolio1 Kiire alustamine

## 5-minutiline seadistus

### 1️⃣ Sünkroniseeri ACF väljad (30 sekundit)

```
WordPress Admin → Custom Fields → Tools → Sync
→ Leia "Portfolio1 Block" → Kliki "Sync"
```

✅ Valmis! Väljad on nüüd sünkroniseeritud.

### 2️⃣ Lisa blokk lehele (30 sekundit)

```
1. Ava leht Gutenberg editoris
2. Kliki "+" nuppu
3. Otsi "Portfolio1"
4. Kliki blokil
```

✅ Blokk on lehel!

### 3️⃣ Lisa kategooriad (1 minut)

```
Kategooria 1:
- Nimi: Kõik Kodulehed
- Slug: koik

Kategooria 2:
- Nimi: Veebilehed
- Slug: veebilehed

Kategooria 3:
- Nimi: Eridisain
- Slug: eridisain
```

✅ Kategooriad on valmis!

### 4️⃣ Lisa esimene töö (3 minutit)

**Põhiinfo:**
```
Kategooria: eridisain
Kategooria silt: Eridisain
Pealkiri: Kalle beds
Kirjeldus: Persona pakub personali- ja palgaarvestust...
Nupu tekst: Vaata lehte
Nupu link: https://example.com
```

**Pildid:**
```
Peamine pilt: Lae üles (1200x800px)
Screenshot pilt: Lae üles (800x600px) - valikuline
```

**Lähteülesanne:**
```
Pealkiri: Lähteülesanne
Sissejuhatus: Uuele lehele seadis klient 4 peamist ülesannet:
Punktid:
1. Uue brändi identiteedi loomine
2. Kasutajasõbraliku liidese disain
3. Mobiilne responsiivsus
```

**Lahendus:**
```
Pealkiri: Lahendus
Tekst: Lõime kaasaegse ja kasutajasõbraliku veebilehe...
```

**Statistika (valikuline):**
```
Enne: 150
Pärast: 450
Silt: Külastajat kuus
```

✅ Esimene töö on valmis!

### 5️⃣ Salvesta ja vaata (30 sekundit)

```
1. Kliki "Salvesta mustand" või "Uuenda"
2. Kliki "Eelvaade"
3. Vaata tulemust
```

✅ Valmis! Portfolio1 töötab!

## Kiire tõrkeotsing

### ❌ Blokk ei ilmu

**Lahendus:**
1. Kontrolli ACF Pro aktiveerimist
2. Sünkroniseeri väljad uuesti
3. Tühjenda vahemälu (Ctrl+Shift+R)

### ❌ Stiilid puuduvad

**Lahendus:**
1. Tühjenda brauseri vahemälu (Ctrl+Shift+R)
2. Kontrolli teema versiooni (peaks olema 1.8.7+)

### ❌ Filtreerimine ei tööta

**Lahendus:**
1. Kontrolli, et kategooria slug vastab
2. Kontrolli, et slug on õigesti sisestatud (väiketähed)

### ❌ Akordion ei avane

**Lahendus:**
1. Tühjenda brauseri vahemälu
2. Kontrolli brauseri konsooli (F12)
