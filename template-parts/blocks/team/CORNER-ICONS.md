# Nurga Ikoonid - Team Block

## 🎯 Ülevaade

Nurga ikoonid on valged ikoonid, mis ilmuvad meeskonnaliikme pildi vasakus ülanurgas, kui kasutaja hõljutab hiirt pildi peale (hover efekt).

## 📋 Saadaolevad Ikoonid

### 1. X (diagonaalid) - `x`
```
Kaks diagonaalset joont, mis ristuvad
Klassikaline X kujund
Vaikimisi valik
```

### 2. Täht (Star) - `star`
```
16-haruline täht
Keerukam, detailsem disain
Uus ikoon!
```

### 3. Rist (Cross +) - `cross`
```
Pluss märk (+)
Vertikaalne ja horisontaalne joon
Lihtne ja selge
```

### 4. Ring (Circle) - `circle`
```
Lihtne ring
Minimalistlik
```

### 5. Tärn (Asterisk) - `asterisk`
```
8-haruline tärn
Keerukas, detailne
```

### 6. Ei näita - `none`
```
Ikoon puudub
Kasulik, kui soovid ainult teksti ja väikest pilti
```

## 🎨 Kuidas Kasutada

1. **Lisa meeskonnaliige** Team blokki
2. **Lisa hover tekst** - ilma selleta ei saa ikooni valida
3. **Vali nurga ikoon** dropdown menüüst:
   - Ei näita
   - X (diagonaalid)
   - Täht (Star) ⭐ UUS!
   - Rist (Cross +)
   - Ring (Circle)
   - Tärn (Asterisk)

## 🎨 Disaini Soovitused

### Ühtne Stiil
Kasuta sama ikooni kõigile meeskonnaliikmetele, kellel on hover efekt:
```
Diana - Ei näita (ei ole hover'it)
Tanel - Täht (Star)
Marian - Täht (Star)
Daniel - Ei näita (ei ole hover'it)
```

### Segatud Stiil
Kasuta erinevaid ikoone erinevate rollide jaoks:
```
Juht - Täht (Star)
Arendaja - Rist (Cross)
Disainer - Tärn (Asterisk)
```

## 🔧 Tehnilised Detailid

### SVG Parameetrid
- Suurus: 42x42px
- Värv: Valge (`stroke="white"`)
- Joonejämedus: 1.4px (`stroke-width="1.4"`)
- ViewBox: `0 0 42 42`

### CSS Klassid
- `.block-team__corner-icon` - Konteineri klass
- Positsioon: `top: 25px; left: 25px;`
- Opacity: `0` (tavaline), `1` (hover)
- Transitsioon: `0.3s ease`

### ACF Välja Väärtused
```json
{
  "none": "Ei näita",
  "x": "X (diagonaalid)",
  "star": "Täht (Star)",
  "cross": "Rist (Cross +)",
  "circle": "Ring (Circle)",
  "asterisk": "Tärn (Asterisk)"
}
```
